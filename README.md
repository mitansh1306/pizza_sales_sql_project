# 🍕 Pizza Sales Analysis Using SQL

## 📌 Project Overview

This project analyzes a real-world pizza sales dataset using **MySQL** to uncover valuable business insights. The analysis focuses on sales performance, customer purchasing behavior, product popularity, and revenue trends using advanced SQL queries.

## 🎯 Objectives

* Analyze overall sales performance.
* Identify best-selling and least-selling pizzas.
* Track daily and monthly sales trends.
* Evaluate category-wise and size-wise performance.
* Generate insights to support business decision-making.

## 🛠️ Technologies Used

* MySQL
* SQL

## 📚 SQL Concepts Applied

* SELECT Statements
* WHERE, GROUP BY & ORDER BY
* Aggregate Functions
* INNER JOINs
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions
* Date & Time Functions
* LIMIT

## 📊 Key Business Insights

* Calculated total revenue, total orders, and average order value.
* Identified the top-selling pizzas by revenue and quantity.
* Analyzed sales trends across different days and months.
* Compared pizza categories and sizes based on sales performance.
* Ranked products using SQL Window Functions.
* Computed cumulative revenue over time.

## 📂 Dataset

The project uses a pizza sales dataset containing:

* Pizza Types
